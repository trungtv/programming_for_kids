# Bài giảng 1.5: Giới thiệu về Blocks (Khối lệnh)

## 📋 Thông tin bài học
- **Thời gian**: 45 phút
- **Độ tuổi**: 8-9 tuổi
- **Trình độ**: Cơ bản

## 🎯 Mục tiêu học tập

### Kiến thức
- Hiểu blocks (khối lệnh) là gì trong Scratch
- Biết các loại blocks khác nhau và chức năng của chúng
- Hiểu cách kết hợp blocks để tạo chương trình
- Biết cách đọc và hiểu code Scratch

### Kỹ năng
- Nhận biết và phân loại các blocks
- Kết hợp blocks để tạo chương trình đơn giản
- Đọc và hiểu code Scratch
- Sử dụng blocks hiệu quả

### Thái độ
- Phát triển tư duy logic
- Rèn luyện tính cẩn thận
- Khuyến khích khám phá và thử nghiệm

## 🧠 Nội dung bài học

## 📚 PHẦN LÝ THUYẾT (25 phút)

### Phần 1: Khái niệm Blocks qua hoạt động không máy tính (15 phút)

#### Hoạt động khởi động - "Lắp ráp LEGO"
- **Hoạt động**: Học sinh quan sát khối LEGO và thảo luận
- **Câu hỏi**: "Khối LEGO có thể làm gì? Làm sao để tạo một mô hình?"
- **Kết nối**: "Trong Scratch, chúng ta cũng có các 'khối' để lắp ráp thành chương trình"
- **Mục tiêu**: Hiểu blocks như các khối lắp ráp để tạo chương trình

#### Khái niệm Blocks qua ví dụ thực tế
- **Định nghĩa**: Blocks (khối lệnh) là các lệnh có sẵn trong Scratch để điều khiển nhân vật
- **Ví dụ thực tế**: 
  - Giống như khối LEGO: mỗi khối có chức năng riêng
  - Giống như từ vựng: mỗi từ có ý nghĩa riêng
  - Giống như công thức nấu ăn: mỗi bước là một lệnh
- **Đặc điểm**: 
  - Mỗi block có màu sắc riêng (dễ nhận biết)
  - Có thể kết hợp với nhau (lắp ráp)
  - Có hình dạng khác nhau (phù hợp với nhau)

#### Hoạt động thực hành - "Phân loại blocks"
- **Hoạt động**: Học sinh được phát thẻ có tên các blocks, phân loại theo màu
- **Mục tiêu**: Hiểu các loại blocks khác nhau
- **Kết quả**: Nhận ra blocks được phân loại theo chức năng

### Phần 2: Các loại Blocks trong Scratch (10 phút)

#### Giới thiệu các loại blocks
- **Motion (Chuyển động)** - Màu xanh dương: Di chuyển, xoay, đặt vị trí
- **Looks (Giao diện)** - Màu tím: Nói, thay đổi trang phục, hiệu ứng
- **Sound (Âm thanh)** - Màu hồng: Phát âm thanh, nhạc
- **Events (Sự kiện)** - Màu vàng: Khi cờ xanh, khi nhấn phím
- **Control (Điều khiển)** - Màu cam: Lặp lại, nếu-thì, chờ
- **Sensing (Cảm biến)** - Màu xanh lá: Chạm, khoảng cách, hỏi
- **Operators (Toán học)** - Màu xanh lá nhạt: Cộng, trừ, nhân, chia
- **Variables (Biến số)** - Màu cam: Tạo và sử dụng biến số

#### Hoạt động không máy tính - "Mô phỏng blocks"
- **Hoạt động**: Học sinh đóng vai blocks, thực hiện hành động
- **Ví dụ**: 
  - Block "di chuyển 10 bước" → học sinh bước 10 bước
  - Block "nói 'Xin chào'" → học sinh nói "Xin chào"
  - Block "phát âm thanh" → học sinh tạo âm thanh
- **Mục tiêu**: Hiểu mỗi block thực hiện một hành động cụ thể
- **Kết quả**: Nhận ra blocks là các lệnh để điều khiển nhân vật

## 💻 PHẦN THỰC HÀNH SCRATCH (20 phút)

### Phần 3: Khám phá các loại Blocks (10 phút)

#### Bước 1: Khám phá Motion Blocks
```scratch
# Thử các blocks chuyển động

quay bên phải (90) độ
di chuyển (10) bước
quay bên trái (90) độ
```

```scratch
# Thử các blocks giao diện
Khi cờ xanh được nhấn
nói [Xin chào!] trong (2) giây
thay đổi hiệu ứng [màu v] bởi (25)

```

#### Bước 3: Khám phá Sound Blocks
```scratch
# Thử các blocks âm thanh
Khi cờ xanh được nhấn
phát âm thanh [meow v]
chờ (1) giây
phát âm thanh [pop v]
```

#### Hoạt động mở rộng - "Tạo chương trình đơn giản"
- **Hoạt động**: Kết hợp các loại blocks để tạo chương trình
- **Mục tiêu**: Hiểu cách kết hợp blocks
- **Thử thách**: Tạo chương trình có ít nhất 3 loại blocks khác nhau

### Phần 4: Kết hợp Blocks để tạo chương trình (10 phút)

#### Bài toán: Tạo nhân vật tự giới thiệu
- **Mục tiêu**: Nhân vật di chuyển, nói, và phát âm thanh

#### Lập trình kết hợp blocks
```scratch
# Chương trình tự giới thiệu
Khi cờ xanh được nhấn
# Motion: Di chuyển
di chuyển (50) bước
chờ (1) giây

# Looks: Nói
nói [Xin chào! Tôi là mèo Scratch] trong (3) giây
chờ (1) giây

# Sound: Phát âm thanh
phát âm thanh [meow v]
chờ (1) giây

# Motion: Xoay
quay bên phải (360) độ
chờ (1) giây

# Looks: Thay đổi hiệu ứng
thay đổi hiệu ứng [màu v] bởi (50)
nói [Tạm biệt!] trong (2) giây
```

#### Hoạt động mở rộng - "Tạo chương trình riêng"
- **Hoạt động**: Học sinh tạo chương trình riêng với nhiều loại blocks
- **Mục tiêu**: Thực hành kết hợp blocks
- **Thử thách**: Tạo chương trình có ít nhất 5 loại blocks khác nhau

## 🔗 Kết nối với lập trình thực tế

### Khái niệm tương đồng

#### 1. Functions/Methods (Hàm/Phương thức)
- **Scratch**: Blocks là các lệnh có sẵn
- **Lập trình**: Functions/methods là các đoạn code có thể gọi
- **Ví dụ**: 
  - Scratch: `di chuyển (10) bước`
  - Python: `move(10)`
  - JavaScript: `move(10)`

#### 2. API (Application Programming Interface)
- **Scratch**: Blocks là API có sẵn
- **Lập trình**: API cung cấp các hàm có sẵn để sử dụng
- **Ví dụ**: 
  - Scratch: Blocks trong palette
  - Python: `print()`, `len()`, `input()`
  - JavaScript: `console.log()`, `document.getElementById()`

#### 3. Commands (Lệnh)
- **Scratch**: Mỗi block là một lệnh
- **Lập trình**: Mỗi câu lệnh là một lệnh
- **Ví dụ**: 
  - Scratch: `nói [Xin chào]`
  - Python: `print("Xin chào")`
  - JavaScript: `console.log("Xin chào")`

### Ví dụ trong lập trình thực tế

#### Python
```python
# Tương tự blocks trong Scratch
print("Xin chào!")  # Looks block: nói
import random
x = random.randint(1, 10)  # Operators block: số ngẫu nhiên
```

#### JavaScript
```javascript
// Tương tự blocks trong Scratch
console.log("Xin chào!");  // Looks block: nói
let x = Math.random() * 10;  // Operators block: số ngẫu nhiên
```

## 💡 Lưu ý quan trọng

### Tại sao cần hiểu Blocks?
- **Nền tảng**: Blocks là nền tảng của mọi chương trình Scratch
- **Đọc code**: Hiểu blocks giúp đọc và hiểu code dễ dàng hơn
- **Tư duy lập trình**: Blocks giúp phát triển tư duy lập trình
- **Chuẩn bị tương lai**: Hiểu blocks giúp chuyển sang lập trình văn bản dễ hơn

### Cách học Blocks hiệu quả
- **Khám phá**: Thử các blocks mới và quan sát kết quả
- **Thử nghiệm**: Thay đổi giá trị trong blocks và xem điều gì xảy ra
- **Kết hợp**: Kết hợp nhiều blocks để tạo chương trình phức tạp hơn
- **Đọc code**: Đọc code của người khác để học cách sử dụng blocks

### Mẹo hay
- **Màu sắc**: Nhớ màu sắc của từng loại block để tìm nhanh hơn
- **Hình dạng**: Hiểu hình dạng blocks (vuông, tròn, mũ) giúp biết cách kết hợp
- **Thử nghiệm**: Không sợ thử các blocks mới, thử và quan sát kết quả
- **Đọc tên**: Tên block thường mô tả chức năng của nó
