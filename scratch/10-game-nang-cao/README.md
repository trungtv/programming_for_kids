# Topic 10: Lập trình game nâng cao

## 📋 Giới thiệu

Topic này giúp học sinh tạo ra các game phức tạp với các hệ thống game mechanics nâng cao. Đây là cách tốt nhất để trẻ học tư duy phức tạp mà vẫn vui.

## 📚 Các bài học trong topic

### Bài 12A: Hệ thống vật phẩm / Inventory
- **File**: `bai-giang-12a-he-thong-vat-pham.md` *(Chưa tạo)*
- **Mục tiêu**: Tạo hệ thống quản lý vật phẩm trong game
- **Kiến thức**:
  - Thêm/xóa item vào list
  - Kiểm tra có item hay không
  - Sử dụng item
  - Quản lý inventory
- **Thời gian**: 90 phút
- **Yêu cầu**: Đã hoàn thành Bài 6 (list) và Bài 3.5 (custom blocks)

### Bài 12B: AI đơn giản cho kẻ thù
- **File**: `bai-giang-12b-ai-ke-thu.md` *(Chưa tạo)*
- **Mục tiêu**: Tạo AI đơn giản cho kẻ thù trong game
- **Kiến thức**:
  - Đuổi theo người chơi
  - Tránh vật cản
  - Patrol (đi tuần tra)
  - Kết hợp nhiều hành vi
- **Thời gian**: 90 phút
- **Yêu cầu**: Đã hoàn thành Bài 3 (clone) và Bài 11C (tìm đường)

### Bài 12C: Hệ thống điểm & khó dần
- **File**: `bai-giang-12c-he-thong-diem-va-kho-dan.md` *(Chưa tạo)*
- **Mục tiêu**: Tạo hệ thống game loop phức tạp
- **Kiến thức**:
  - Tốc độ tăng theo thời gian
  - Sinh vật xuất hiện nhiều dần
  - Game loop phức tạp
  - Cân bằng độ khó
- **Thời gian**: 90 phút
- **Yêu cầu**: Đã hoàn thành Bài 3 (hệ thống điểm) và Bài 12A, 12B

## 🎯 Kiến thức đạt được

Sau khi hoàn thành topic này, học sinh sẽ:
- Biết cách tạo hệ thống vật phẩm phức tạp
- Hiểu cách tạo AI đơn giản cho game
- Có thể thiết kế game loop và cân bằng độ khó
